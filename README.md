# 瓷时 · Porcelain Time

**你的生日，藏着一件中国瓷器。**

输入出生月份和日期，遇见一件真实藏于博物馆的中国陶瓷作品——朝代、窑口、工艺，以及它与你这一天之间的关联。

纯静态站点：HTML + CSS + 原生 JavaScript，无构建步骤，无后端依赖。打开 `index.html` 即可运行。

在线体验：<https://project-48930c91.eazo.dev>

## 怎么玩

1. 在首页选择出生的**月**与**日**。
2. 点击「发现我的瓷器」，一段圆形纹样转场后进入结果页。
3. 结果页从上到下是：馆藏图版与来源、巨型生日日期、作品中英文名、历史时期与窑口、三段编号章节（故事 / 工艺 / 你的生日与它的相遇）。
4. 「重新探索」回到首页；「分享我的瓷器」把卡片图与一段文字写入剪贴板。

生日可直接分享成链接，形如 `#/04-08`，打开即直达该天的结果。

## 三种匹配模式（诚实优先）

数据集里每件作品的年代都是**区间**，多数无法精确到某一天。所以匹配永远不假装精确，而是明确告诉你今天是哪一种：

| 模式 | 标签 | 含义 |
| --- | --- | --- |
| **同日事件** | Verified historical date | 这一天在陶瓷史上确实发生过可考事件，作品即与该事件相关 |
| **相邻事件** | Nearest event | 5 天内有可考事件，指向该事件与作品 |
| **主题关联** | Thematic match | 没有确切日期，按作品的季节/月份气质确定性匹配 |

目前收录 5 个可考历史日期（法门寺地宫开启、成化斗彩鸡缸杯香港拍卖、景德镇手工制瓷技艺入选国家级非遗、郑和首下西洋、伦敦中国艺术国际展览会）。

原则：**绝不为一件作品编造创作日期。**

## 数据集

`js/data.js` 收录 20 件作品，跨唐至清：越窑、定窑、汝窑、官窑、龙泉青瓷、青白瓷、元青花、永乐宣德青花、成化斗彩、嘉靖鱼藻罐、康熙豇豆红、雍正铜红与粉彩、乾隆器。

每件包含中英文名、朝代、大致年代、窑口、馆藏或拍卖来源、纹样母题，以及中英双语的「故事」与「工艺」两段。

## 文件结构

```
index.html          页面骨架与两栏结构
styles.css          主样式（山水层叠视觉、响应式断点）
result.css          结果页与分享视图样式
app.js              视图切换、日期选择、结果渲染、视口高度计算
share.js            Canvas 分享卡片绘制
i18n.js             中/英界面文案切换
js/data.js          20 件陶瓷作品数据
js/events.js        可考历史日期事件
js/match.js         生日匹配算法（三种模式）
locales/            界面文案资源
assets/art/         作品图片
assets/bg/          背景纹理
assets/hero-vase.webp  首页浮空青花瓶
docs/screens/       README 截图
.vercelignore       仅用于 Vercel 部署时排除敏感文件
```

## 本地运行

因为用到 `fetch` 与相对路径，建议起一个静态服务器而不是直接双击打开：

```bash
python3 -m http.server 8080
# 打开 http://localhost:8080
```

## 部署

**GitHub Pages**：Settings → Pages → Source 选 `Deploy from a branch`，分支 `main`，目录 `/ (root)`。站内全用相对路径，放在 `/<repo>/` 子路径下也能正常工作。

**Vercel / Netlify**：直接导入仓库，无需 build command，输出目录填 `.`。
